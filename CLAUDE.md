# pran-ker.github.io

Personal site for Prannay Hebbar (prannayh.com). Static, hand-written HTML, CSS and ES modules; no build step, no framework. Deployed on GitHub Pages (`.nojekyll` is present, so every folder publishes; `CNAME` holds the domain).
**Status**: active. Design system "WHITE" (v2, September 2026).

## Run
- dev: `python3 -m http.server 8765` from the repo root (every asset path is root-absolute, so the site must be served from `/`).
- test: none automated. Verify in a browser at 1440, 1024 and 390 with the console open; the site's rule is zero page-originated console errors and no horizontal scroll at any of the three widths. Reduced-motion and no-WebGL both fall back to the CSS cubes (`.ice-fallback`). Headless Chrome floors its window at 500px, so phone widths need a same-origin iframe wrapper (a throwaway HTML file in the repo root, deleted afterwards) that sets `sessionStorage['white.entered']='1'` to skip the gate and reports `documentElement.scrollWidth` for the overflow check.

## Layout
- Pages are `<dir>/index.html`: `/blog`, `/blog/<essay>` (four essays), `/principles`, `/gallery`, `/more`, `/contact`, `/post`, plus root `index.html` and `404.html`. Canonicals have no trailing slash; GitHub Pages serves `/blog` as `/blog/` and the router treats the two as one path.
- Every page carries the same shell, copied from `index.html` verbatim: `<html lang="en" data-page="home|writing|essay|principles|gallery|more|contact|void">`, the head boilerplate (fonts, `white.css`, modulepreloads, `white.js`), the skip link, `<canvas id="cubes">`, `.floor`, `.ice-fallback`, `#gate`, `header.hud` (wordmark · nav · transport), `main#main[data-page]`, `footer.foot`. Only `<title>`, description/og/twitter/canonical, `data-page` and the nav's `aria-current` differ between pages. `<main data-nav="/more">` tells the shell which nav item a page sits under when its path does not say.
- Footer is exactly: the profile links row + the base line (© 2026 Prannay Hebbar · San Francisco). No track credit, no engineering note, no map credit in the footer (Prannay cut all three); the track is credited in the transport and the OpenStreetMap attribution the ODbL asks for lives as a `title` on the montage element in `index.html`.
- Page-specific CSS lives in one `<style data-page>` as the first child of `<main>`, every selector scoped under `main[data-page="…"]`. Page JS lives in `<script type="module" data-page>` inside `<main>`; static imports of `/assets/js/*` are fine. The router re-executes these after a swap (it recreates them as inline modules), so a page script must be idempotent, must bind only inside `#main`, and must tear down anything global on the `white:navigate` event.

## Shell files (`assets/`)
- `css/white.css` — the whole design system: tokens (`--t*` type scale, `--s*` spacing, `--ink/--graphite/--ash/--hair`, `--signal` for live state only, `--fig-accent` as the one figure tint), the shell chrome, and every shared component (`.sh` section head, `.rows/.row`, `.essay/.prose/.fig/.pull/.fn/.pn`, `.subnav`, `.gallery*`, `.pill`, `.covers`, transport states). The component index at the top of the file is the contract; read it before styling anything, and add there rather than in a page when a pattern repeats.
- `js/white.js` — the shell: gate (focus-trapped dialog; the YouTube player is created during the gate so playback starts synchronously inside the enter gesture — do not defer it), music (`DpYfeTNkodQ`, Lane 8 "Little Voices"; hidden IFrame API player; states idle/loading/blocked/playing/paused/lost; mute and volume persisted in localStorage, entered flag in sessionStorage), the transport HUD (title · artist · mute · elapsed · beat dot; "Tap for sound" / "Retry sound" appear only when audio was blocked or the API failed; the beat dot is filled and pulsing only while `data-status="playing"`), the client-side router (same-origin `<a>` clicks fetch the destination, abort any in-flight fetch, cross-fade `#main`, swap title/description/canonical/robots/og/twitter/JSON-LD, push history with scroll positions, re-run page scripts, focus `#main`, and call `cubes.setMode`), the HUD height sync (`--top`), reveal-on-scroll, media controls, and the auto-mounts: `[data-montage]` → `montage.js`, `[data-gallery]` → `gallery.js`, both dynamically imported only when needed.
- `js/cubes.js` + `js/cubes-interact.js` — the three.js cube field (frosted-glass ShaderMaterial, hairline edges, 125-BPM breath as a wave through the field, distance fade, HUD dissolve so no cube is ever cut by the header). One formation per `data-page` mode, seeded by the mode name (essays add their path, so each essay owns an arrangement); the field relayouts with damping on every route change and never sits behind body text. Visitors can drag, throw and click-to-tint cubes; that is intentional and gets no UI chrome. WebGL is probed on a throwaway canvas first; without it the module returns null and the CSS cubes show.
- `js/montage.js` + `js/montage-frames.js` — the Trajectory montage on the home page: inline SVG frames of real vector geometry (OSM streets/coastline/water under ODbL, US states GeoJSON), rendered as a rapid cut with a hairline itinerary; a still frame plus "Play the sequence" under reduced motion. `montage-frames.js` is generated (the build script lived in the redesign's scratch folder, `/tmp/psite-src/geo/build.py`); edit the montage's copy in `index.html`, not the frames. Exports of the same frames: `assets/images/trajectory.gif` (the `<noscript>` fallback), `trajectory.webm` (deliverable, unreferenced by pages) and `opengraph.png` (1200×630, the site's og:image). Because the geometry is OSM, keep the ODbL attribution on the montage element (`title` attribute); it was removed from the footer at Prannay's request.
- `js/gallery.js` — the masonry (JS shortest-column layout, FLIP transitions on filter, filter state in the URL hash, lightbox with ←/→/Esc and focus return).
- `vendor/` — `three.module.min.js`, `marked.esm.js`, `highlight.esm.js`, `katex/` (its `katex.min.mjs` is imported relatively by `contrib/auto-render.mjs`). `fonts/` — woff2 only, each referenced by an `@font-face`.

## Gallery
- Photos and clips live in `assets/gallery/{full,thumb,video}` and are described by `assets/gallery/manifest.json` (id, album, albumTitle, year, kind, src, thumb/poster, w, h, duration). Every file there is a processed copy: resized, re-encoded and EXIF-stripped; the originals are not in the repo. Album keys are stable ids (e.g. `mc` = "Around the Bay"); the visible title comes from `albumTitle`. To add media, produce the same three renditions, strip metadata, and append to the manifest; `<img width height>` come from `w`/`h`, so both must be right.

## Content and old URLs
- `/post#<slug>` fetches `/content/<slug>.md` first and falls back to `/content/<slug>.html`, then renders with marked (+ highlight / katex only when a document needs them); `.html` documents are stripped of their own `<style>` and `style=` attributes so they render in the column's type. Every path under `content/` is therefore URL-addressable: never move or rename content files. `content/blog-posts.json` drives the prev/next rail; today it lists only two legacy placeholders (`test-blog`, the empty `coding-agents-is-all-you-need`), so the rail never shows for a real document. Those two, `content/blogs/_design-style.md` and the old `content/tldr/resume.html` are pre-redesign files kept only because the paths are addressable; deleting them is Prannay's call, not a polish pass's. `/post` is `noindex`; the same principles documents render inline on `/principles`, and the `/content/principles/*.md` files must stay in step with that page.
- Root-level `blogs.html`, `detail.html`, `model-watermarking.html`, `other-stuff.html` are redirect stubs preserving old URLs — keep them.
- The research poster feed (`/research-read`) was removed in September 2026 at Prannay's request; its old URLs now 404.
- `robots.txt` disallows `/post`; `sitemap.xml` lists the public pages. Add a line when a page is added.

## Constraints
- Live site: page URLs, content paths and `<head>` metadata are load-bearing.
- Every element earns its place: no coordinates, spec blocks, counters, ticking readouts, decorative numerals, invented status labels. Public facts only; never addresses, phone numbers, salaries, emails. The line is "Founder, San Francisco." — never "pre-launch". VIT appears once, as a clause in About.
- Typography and spacing come from the tokens: 18px serif for reading, 11px mono minimum for metadata in `--ash` or darker; figure annotations are sentence-case mono (`.f-m`), uppercase is reserved for `.fig__meta`, `.essay__meta`, `.sh__meta` and the transport. The one figure accent is `--fig-accent` under an ink hairline; the only second hue is spec-rewards' `--fig-blue`, because there the colour is the content.
- Do not reintroduce a play/pause button (`.tp-play`), a second header or footer style, or per-page copies of shell components.
